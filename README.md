# بوت أذكار تليجرام 📿

يرسل أذكار **الصباح** و**المساء** و**النوم** تلقائياً عبر GitHub Actions، وفيه قائمة (أذكار الصباح/المساء/النوم/الاستيقاظ/بعد الصلاة) تختار منها.

## الإعداد
1. أنشئ بوت من [@BotFather](https://t.me/BotFather) وخذ **التوكن**.
2. أرسل `/start` للبوت (أو أضفه لقناة/مجموعة كمشرف)، واعرف **chat id** (مثلاً من @userinfobot، أو القناة `@channel_name`).
3. في المستودع: *Settings → Secrets and variables → Actions* أضف:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
4. الإرسال التلقائي يعمل حسب الجدول في `.github/workflows/azkar.yml` (الأوقات UTC — عدّلها لبلدك).

## الاستخدام
- **يدوياً**: تبويب *Actions → Azkar → Run workflow* واختر الذكر.
- **من تليجرام**: ابعت `/menu` للبوت واضغط على الذكر المطلوب (الرد خلال ≤5 دقائق عبر `menu.yml`).
- **إضافة/تعديل أذكار**: عدّل `azkar.json` فقط.

> ملاحظة: GitHub قد يؤخر الـ cron بضع دقائق، ويوقف الجداول بعد 60 يوماً بدون نشاط في المستودع.
