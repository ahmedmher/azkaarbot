# بوت أذكار تليجرام 📿

بوت يرسل أذكار **الصباح** و**المساء** و**النوم** تلقائياً، وفيه قائمة أذكار يختار منها المستخدم، ولوحة تحكم كاملة للأدمن من تليجرام. يعمل بالكامل على GitHub Actions.

## الإعداد
1. أنشئ بوت من [@BotFather](https://t.me/BotFather) وخذ التوكن.
2. في المستودع: *Settings → Secrets and variables → Actions* أضف `TELEGRAM_BOT_TOKEN`.
   (اختياري) `TELEGRAM_CHAT_ID` لو عاوز الأذكار التلقائية تروح كمان لقناة/مجموعة.
3. الأدمن الافتراضي `552728145` (غيّره بإضافة متغير `ADMIN_ID` في الـ workflow).
4. فعّل Actions، وشغّل **Bot** مرة من تبويب Actions (بعدها يشتغل تلقائياً كل 5 دقائق).

## للمستخدم
- `/start` أو `/menu`: قائمة الأذكار، اضغط على ما تريد.
- 🔔 إشعاراتي: تفعيل/إيقاف أذكار الصباح والمساء والنوم التلقائية.

## للأدمن (`/admin`)
- 📢 **بث رسالة للجميع** (أو `/broadcast نص الرسالة`) مع معاينة وتأكيد قبل الإرسال.
- 📤 **إرسال قسم للجميع** في أي وقت.
- 📚 **إدارة الأذكار**: إضافة قسم جديد، إضافة/حذف ذكر، تغيير اسم القسم، إخفاء/إظهار، حذف قسم. كل شيء يُحفظ ويظهر للمستخدمين فوراً.
- 📊 إحصائيات المستخدمين.
- `/cancel` يلغي أي خطوة جارية.

## التشغيل التلقائي
- `.github/workflows/azkar.yml`: الإرسال المجدول (الأوقات UTC، الافتراضي توقيت القاهرة)، ويمكن تشغيله يدوياً لإرسال أي قسم لكل المستخدمين.
- `.github/workflows/menu.yml`: يستقبل رسائل تليجرام ويحفظ الحالة في `data/state.json`.

## ملاحظات مهمة
- الرد على الرسائل شبه فوري، لكن قد يتأخر حتى ~30 ثانية عند تبديل الدورة كل 5 دقائق.
- `data/state.json` يحتوي أرقام (IDs) المستخدمين فقط بدون أسماء. لو المستودع **Public** فالملف ظاهر للجميع؛ الأفضل جعل المستودع **Private**، لكن وقتها استهلاك دقائق Actions كبير (الخطة المجانية 2000 دقيقة/شهر) فقلّل `LOOP_SECONDS` أو زِد فاصل الـ cron.
- GitHub قد يؤخر الـ cron بضع دقائق، ويوقف الجداول بعد 60 يوماً بدون نشاط في المستودع.
- `azkar.json` هو المصدر الأولي فقط؛ بعد أول تشغيل التعديلات تتم من تليجرام وتُخزَّن في `data/state.json`.
